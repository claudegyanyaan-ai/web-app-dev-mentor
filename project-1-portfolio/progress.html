Concepts introduced

Full plain-English explanations in CONCEPTS.md. Summary:

  • DOCTYPE, head vs body, viewport meta tag
  • Linking external CSS/JS; why scripts load at the end of body
  • Semantic HTML tags (header/nav/main/section/footer) vs generic divs
  • Anchor-link navigation as zero-JS client-side routing
  • CSS reset, Flexbox layout, media queries (mobile-responsive design)
  • DOM selection (querySelector), events (addEventListener), classList.toggle
  • Browser DevTools: Network tab for diagnosing missing/broken linked files
  • Static hosting, HTTPS-by-default, free-tier deploy via Vercel + GitHub integration
  • Git basics: init, add, commit, push, remote; why rewriting pushed history is risky

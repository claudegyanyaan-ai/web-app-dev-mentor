Bug fixed — Delete button not rendering: traced to a stale Turbopack dev-server cache. Fixed with a full server restart (Ctrl+C, then npm run dev again) — a good general troubleshooting step when saved code isn't reflecting in the browser.
Bug fixed — Vercel build failed with "Module not found": the components folder was locally named Components (capital C), which Windows' case-insensitive filesystem tolerated but Vercel's Linux build environment did not. Fixed via a two-step git mv rename to force Git to register the case change.

Concepts introduced

Full plain-English explanations in CONCEPTS.md. Summary:

  • Components — small reusable functions that return UI
  • JSX — HTML-like syntax embedded in JavaScript
  • Props — how data and behavior flow into a component from its parent
  • useState — React-managed data that triggers automatic re-renders
  • Never mutate state directly — always build a new array/object (spread, map, filter)
  • useEffect — syncing with something outside React (localStorage)
  • "use client" — marking a component as needing to run in the browser
  • The build step — why Next.js needs "npm run build" before deployment
  • OS case-sensitivity — why code that works locally can fail once deployed
